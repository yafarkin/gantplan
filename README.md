# GantPlan

Автоматический планировщик проектов на .NET 8: на входе — дерево задач с
ограничениями (оценки, зависимости, приоритеты, дедлайны, доступные
исполнители), на выходе — рассчитанные даты и назначенные исполнители по
каждой задаче. Планирование делает не эвристика, а честный
constraint-programming солвер (Google OR-Tools CP-SAT), учитывающий
календари (выходные, отпуска, недоступность ресурсов) и уже выполненную
часть работы при перепланировании.

Подробное описание архитектуры и доменной модели — в [explain.md](explain.md).

## Структура решения

- **GantSolver** — библиотека: доменные модели (`Dtos`), логика солвера
  (`Logic`), подготовка данных для визуализации и HTML-шаблон дерева задач
  (`Visualize`, `Templates`).
- **Planner** — консольная точка входа: читает `project.json` (или берёт
  демо-проект), прогоняет солвер, сохраняет результат обратно в
  `project.json` и генерирует `timeline.html`.
- **Tests** — юнит-тесты (NUnit).

## Быстрый старт

```bash
dotnet build
dotnet test
```

Прогнать планировщик на демо-проекте (пока рядом нет `project.json`, возьмётся
`Planner/SourcePlans/DemoProject.cs`) и открыть результат:

```bash
cd Planner
dotnet run
```

После запуска в каталоге появятся `project.json` (входные данные + расчётный
план и факт) и `timeline.html` — дерево задач с поиском, фильтром по
исполнителю и переключением "по задачам" / "по исполнителям"; открывается
прямо с диска, без сервера.

## Стек

.NET 8, Google.OrTools (CP-SAT), Mapster, Newtonsoft.Json.
