# GantPlan

Автоматический планировщик проектов на .NET 8: на входе — дерево задач с
ограничениями (оценки, зависимости, приоритеты, дедлайны, доступные
исполнители), на выходе — рассчитанные даты и назначенные исполнители по
каждой задаче. Планирование делает не эвристика, а честный
constraint-programming солвер (Google OR-Tools CP-SAT), учитывающий
календари (выходные, праздники, отпуска, недоступность ресурсов) и уже
выполненную часть работы: по дате среза солвер сам отмечает прогресс, а
закрытие задач подтверждается вручную.

Подробное описание архитектуры, доменной модели и правил плана/факта — в
[explain.md](explain.md).

## Структура решения

- **GantSolver** — библиотека: доменные модели (`Dtos`), логика солвера
  (`Logic`), отчёты и подготовка данных для визуализации, HTML-шаблон
  таймлайна и встроенный в него d3 (`Visualize`, `Templates`).
- **Planner** — консольная точка входа: берёт план (C#-класс
  `SourcePlans/DemoProject.cs` или, если рядом лежит, `project.json`),
  прогоняет солвер и сохраняет результаты (см. ниже).
- **Tests** — юнит-тесты (NUnit), по темам.

Общие настройки сборки — в `Directory.Build.props` (в т.ч.
`TreatWarningsAsErrors`), стиль кода — в `.editorconfig`. CI (GitHub
Actions) на каждый push в `master` и PR собирает решение в Release и
прогоняет тесты.

## Быстрый старт

```bash
dotnet build
dotnet test
```

Прогнать планировщик на демо-проекте и открыть результат:

```bash
cd Planner
dotnet run
```

Обычный цикл работы: описать план в C#-классе (как
`Planner/SourcePlans/DemoProject.cs`), запустить, посмотреть
`timeline.html`, поправить план, запустить снова. Если рядом с `Planner`
лежит `project.json`, берётся он, а не C#-класс (и `FactDate` при этом
задаётся в `Program.cs`).

Лимит времени солвера по умолчанию — 30 секунд. Для больших планов (квартал,
десятки задач), если в консоли статус `Feasible` (оптимум не доказан),
лимит можно увеличить первым аргументом: `dotnet run -- 120`.

## Что получается на выходе

- **Консоль**: статус решения (`Optimal`/`Feasible`/`Infeasible`/`Unknown`),
  цель, горизонт и время; предупреждения (например, недостижимый `DueDate`);
  список задач, которые ждут подтверждения закрытия; статистика
  распределения времени по кварталу (бизнес/не бизнес/резерв на «влёты»).
- **`timeline.html`** — диаграмма Ганта, открывается прямо с диска и без
  интернета (d3 встроен в страницу). По умолчанию — трек на исполнителя
  (пересекающиеся задачи разносятся по дорожкам, разворачивание трека
  показывает дерево эпиков/задач этого человека), второй режим — дерево
  задач целиком. Поиск по номеру/названию/Jira-ключу, фильтр по
  исполнителю (можно часть слова), нерабочие дни — тем же календарём, что
  и у солвера, колонка «сегодня» на дате среза, задачи, ждущие
  подтверждения закрытия, выделены красной обводкой. В треке исполнителя
  видны его отпуск (штриховка всей строки, даже где задач нет) и границы
  доступности `AvailFrom`/`AvailTo` (оранжевая линия с подписью, вне
  доступности — серая заливка).
- **`daily_plan.txt`** — план по людям и дням на квартал: чем занят каждый
  в каждый рабочий день.
- **`project.json`** — входные данные вместе с расчётным планом и фактом.

## Стек

.NET 8, Google.OrTools (CP-SAT), Mapster, Newtonsoft.Json, d3 7.9.0
(встроен в таймлайн), NUnit.
